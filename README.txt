# KAFOLAT PLAST website

Откройте index.html в браузере.

Это готовый адаптивный макет сайта в бело-красном стиле с вашими фотографиями изделий.
Для настоящего вращения 3D-моделей замените изображения в каталоге на модели GLB/GLTF и подключите Three.js или model-viewer.


Обновление: переключатель языка оставлен только на главной странице index.html. На внутренних страницах язык берётся из localStorage (выбор с главной страницы сохраняется).
